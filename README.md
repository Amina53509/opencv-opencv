# Image Dimension & Color Channels Exploration with OpenCV
The official OpenCV library containing all the core computer vision functions like reading images, splitting channels, and color conversions.
This project demonstrates basic image processing tasks using OpenCV. It covers reading an image, exploring its dimensions, accessing pixel values, splitting into color channels, and visualizing each channel in grayscale and color.

**Features**
Read and display a color image

Print image shape (rows, columns, channels)

Access specific pixel values

Split image into Blue, Green, and Red channels

Display channels in grayscale and actual color

Print the shape of each channel

**Requirements**
Python 3.x

OpenCV (pip install opencv-python)

Matplotlib (pip install matplotlib)

NumPy (pip install numpy)
